# 文章评分卡（100 分制）— 文章组内部工具

> 依据：《头条与微信公众号优质文章及 AI 写稿作业规范》(2026-08-07 调研版) 第八节（vault：`20_Hermes/10_Content_Production/02_Article_Group/头条与微信公众号优质文章及AI写稿作业规范.md`）
>
> 硬规则：**总分 < 75 不发布；真实性与证据 < 15 或 原创判断 < 15 → 一票否决，无论总分。**
>
> 用法：每篇在 S6 通过 style_gate 后填写。机械项由 style_gate/portfolio_gate 输出自动带入；人工项由主编（Allen）逐篇填写。评分卡存档至批次目录 `review/scoring/`。

## 一、机械项（自动带入）

| 维度(分值) | 机械指标 | 判定 | 数据来源 |
|---|---|---|---|
| 真实性与证据 (25) | style_gate `error_total` = 0 | 达标；>0 直接红灯 | verdict.error_total |
| 真实性与证据 (25) | `fact_density` ≥ 1/3（锚点段落占比） | 达标 | articles[i].fact_density |
| 真实性与证据 (25) | `hits` 无未核验断言（`date:release-claim` 等须附撤档史核验记录） | 已核验/未核验 | articles[i].hits |
| 主题与结构 (15) | `opening_hook`/`hook_declaration` ok；无 h3；TOC=3 篇 | 全 ok | articles[i].* |
| 标题与用户价值 (10) | `title_gap` ok（题文一致机械面） | ok | articles[i].title_gap |
| 语言与阅读体验 (5) | `char_count` ∈ [1500, 2200]；风险词扫描 0 命中 | 达标 | articles[i].char_count |
| 合规与标识 (5) | 涉时政/社会事件 → 文末"来源"行存在（正文不招供原则下）；非涉政题材 N/A | 有/无/N/A | 人工核 |

## 二、人工项（主编逐篇填写，各维度内给 0–满分）

| 维度(分值) | 判定问题 | 得分 |
|---|---:|
| 真实性与证据 (25) | 关键数字/日期/引语逐条可追溯？证据表引用完整？ | /25 |
| 原创判断 (20) | 删除来源材料后还剩什么独立判断？判断有边界词吗？ | /20 |
| 信息增量 (20) | 读者看完新增什么？（新数据/新时间线/新比较/新实测/新解释，至少一项） | /20 |
| 主题与结构 (15) | 一个核心问题贯穿？段落递进，无无效展开/强行升华？ | /15 |
| 标题与用户价值 (10) | 题文一致？读者知道能获得什么？ | /10 |
| 语言与阅读体验 (5) | 通读自然？无机器编译感、套话？ | /5 |
| 合规与标识 (5) | AI 声明勾选、来源标注、首发状态、原创声明 | /5 |

**合计：____ / 100**（≥75 才可进入交付；<75 退回 S7 定向重写）

## 三、一票否决清单（红灯，任一项即退）

- [ ] style_gate error > 0
- [ ] 关键事实无来源（证据表缺失项）
- [ ] 虚构数据/引语/人物/案例
- [ ] 换词拼接、无实质修改
- [ ] 标题故意误导/题文不符
- [ ] 同质化红灯：`portfolio_gate --cross-batch` 近 3 批同作品或标题相似 ≥0.85
- [ ] 涉时政/社会事件未标来源；AI 生成未声明（发布侧勾选）

## 四、附：发布侧检查（交付前提醒 Allen，发布动作由真人执行）

- [ ] 头条首发声明 + 72 小时站外窗口确认
- [ ] AI 生成/辅助创作标识按平台功能勾选（正文不出现流程标识）
- [ ] 涉时政/社会事件：文末来源行（`来源：官方账号全称`），不用"网传"作唯一来源
- [ ] 配图版权/授权
- [ ] 留档：选题卡、证据表、AI 使用记录、修改稿、最终稿
