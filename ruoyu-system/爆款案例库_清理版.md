## 📊 爆款分级

| 级别 | 标准 | 用途 |
|------|------|------|
| **S级** | 阅读100万+ / 热搜上榜 / 全网转载 | 必学模板 |
| **A级** | 阅读10万+ / 1000+点赞 / 500+评论 | 重点学习 |
| **B级** | 阅读1万+ / 互动率高于同类3倍 | 参考借鉴 |
| **C级** | 无数据，但标题/结构/金句有亮点 | 只学亮点，不学全篇 |

**铁律**：没有阅读量/点赞数据支撑的 → 自动降为C级。

标题：《**香港台湾大陆都被封过！华语地下禁片5部**》

## 🧰 标题钩子武器库

| 钩子类型 | 公式 | 示例 |
|---------|------|------|
| 数字钩 | [数字]+[结果/对比] | 96岁/2077万/5部 |
| 认知钩 | "你以为X"→"其实Y" | "别急着感动"/"被封过" |
| 情绪钩 | [暴力动词]/"别再"/"求求了" | "撕碎"/"封过！" |
| 利益钩 | "怎么样才能"+[好处] | "先算明白" |
| 悬念钩 | "直到我发现"/"背后的真相" | "人性底色" |
| 身份钩 | [人群]+"[共性]" | "华语"/"国产片" |
| 极端反差钩 | [极端数字/身份]+[普通行为] | 96岁奶奶摆摊还债 |
| 名人钩 | [事件]+[名人A][名人B]难辞其咎 | 汪涵姚晨 |
| 禁忌钩 | 被禁/被封/被删/尺度/地下 | "被封过" |

## 🧰 金句模板库

**对比法**：「不是X，是Y。」「X倒了，Y还在。」
**递进法**：「X。和Y。更Z。」（三短句递进）
**悖论法**：「最大的X，是Y。」「这不是X。这是Y。」
**画面法**：数字+场景切片+五独立短句排比
**身份法**：「X不是一个人，是Y。」

- **公式**：`[冲突动作+时间对比] + [冒号] + [心理学术语] + [正在杀死______]`
- **钩子类型**：极端反差钩（举报2月 vs 孩子自残2月）+ 认知钩（受害者逻辑）+ 悬念钩（杀死自己的宝贝）
- **字数**：29字（❌>28字，但用冒号分割两段，读起来像20字）
- **可复制模板**：`[A做了X月]，[B受害X月]：[她的「______」，正在______]`

- **节奏**：每段1-3行，全书无超过4行的段落；金句密度极高（每2-3段一个）

### 金句库

- "真正伤害孩子的，往往不是学校里的那点摩擦。是「我被欺负了」这个认知，被家长反复强化。"
- "这不是爱。这是创伤的复制。"

- **类型**：追问式 + 邀请站队
- **策略**：`你有没有遇到过「永远觉得自己受害」的人？你们后来怎么样了？`——开放式提问，邀请评论区讲自己的故事
