### 2.1 补料实测带来的额外规则

- **正文禁止"来源自证"**：v2400 首次提交因一句"据潮新闻的报道"被 style_gate 判 2 个 error（规则 `source:据…报道`、`source:媒体+稿件词`）。正文可以点名评论者/机构作说话人（"上观新闻的韩浩月认为…"），但不能写"据某媒体报道/据某平台统计"。**补料越多越容易触发**，playbook 应明示。
- **`thin_section` 提案得到验证**：<150 字的判定会准确命中 v1000 的两个 111 字小节，而 v1800-r2 / v2400 最薄小节为 210 / 215 字，全部干净。

## 3. 提案内容

### 3.1 字数带按 `reference_shape` 分层

| 形态 | 现行 | 建议目标带 | 接受带（±100） |
|---|---|---|---|
| `viewing_commentary` | 1500–2200 | **1700–2600** | 1600–2700 |
| `audience_culture_explainer` | 同上 | **1700–2600** | 1600–2700 |
| `adaptation_comparison` | 同上 | **1800–2600** | 1700–2700 |
| `relationship_plot_recap` | 同上 | **1400–2200** | 1300–2300 |
| `setting_observation` | 同上 | **800–1400** | 700–1500（允许短稿） |

- `min_cjk_chars` 由全局常量改为按形态绑定；`max` 维持 2800 天花板（防注水）。
- 保留例外通道：材料确实不足时可走下限，但**必须在 RUN-RECORD §8 写明材料上限**，不能默认走下限。

### 3.1b 前置条件：字数带由"材料等级"解锁（本提案的关键修正）

容量测算结论：本期四份来源在"每个论点都要有独立来源"的口径下，上限只有 2000–2200 字；写到 2500 字以上会撞上"场面层单一来源"。因此分层带必须配材料门槛，否则就是鼓励注水：

| 材料条件 | 允许写到的目标带 |
|---|---|
| 场面层 ≥8 条且来自 ≥2 个独立来源 + 同口径数据 ≥4 条 | 1800–2600 |
| 场面层 ≥8 条但单一来源（如本期的 c03） | **上限 2000**，且场面必须逐条归属 |
| 无独立场面来源（只有评论与数据） | 1000–1500（`setting_observation` 口径），不得虚构观影细节 |
| 评论者判断条目 ≥40% | 需先补材料，判断类不能充当篇幅主体（本期 47%，是险情） |

对应的材料验收（material acceptance）新增最低量：`min_scene_items`、`min_distinct_scene_sources`、`min_comparable_data_points`；不达标时任务卡不许把 `reference_shape` 定为 `viewing_commentary`。

### 3.1c 新增门禁：来源标题不得当论据

本期实证缺陷：v1000 的三句"结论式论据"分别取自 c02、c03、c04 的**标题**，而非正文证据（"有一篇复盘文章的标题就是结论：姜文没变，观众和时代变了"）。这属于"把信号当事实"的变体，现有门禁没有拦。

建议：`claim-source-check` 增加 `title_as_evidence` 检查——正文引用的判断若在来源中只出现在 `<title>`/H1 层级、正文无对应论述，记为 warning 并需 controller 裁定。

### 3.2 字数由材料反推（写作前强制填写）

```
目标字数 ≈ 开头钉对象与冲突(150–200) + Σ每条硬信息展开(200–300) + 结尾回收(150)
```
- 硬信息条数 N < 4：不动笔，回去补场面层/采访层材料或换题。
- N ≥ 5：目标带按下限之上写，`reader_gain_floor=5` 由"够不够"升级为"每条是否展开到位"。

### 3.3 复核增加一条"薄段"检查

- 任何 H2 小节 < 150 CJK 字 → 记为 `thin_section`（warning，需 controller 判断或补材料）。
- `content-fidelity.json` 中连续 ≥2 个段位登记为"收束未知项" → 记为 `padding_tail`，退回补材料。
（daily-008 art-001 的 s9–s13 正是这个形态。）

### 3.4 对照基准入册（不改门禁，只做可见性）

在 playbook §9 记录：对标 9 篇中位数 2427、历史成稿中位数 1158，作为每期自查的偏离参照；发布后再用同口径完读率/在看/转发校正，单篇数据不升级为长期规律。
