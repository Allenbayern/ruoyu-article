## 二、H2 设问结构

**本型不使用 H2 标题、也几乎不用内嵌设问。** 全文换挡靠两件东西（实测，非推断）：

| 换挡件 | 形态 | 功能 |
| :--- | :--- | :--- |
| **`///` 折行分隔符** | 单独一行 `///` | **18/18 篇**逐字复用；把"账本段"与"补刀段"切开，是本型事实上的段落分节符 |
| **末尾互动问句** | 如 `大家最期待陈思诚的哪一部新片呢？` | 收尾换挡，不承担论证 |

> **对"H2 设问"这一提法的如实说明**：任务要求提取"H2 设问"，但**本样本无 H2**。
> 它属于 `candidate-08` 同族的"**内嵌短问**"写法，而本型**连内嵌设问都极少**——
> 换挡完全由**数字对账**完成。
> 因此本型的高迁移件是**数字对账的换挡**，不是设问。
> 若强行给本型套 H2，会破坏它的推进节奏。**这是本型的结构事实，不是提取遗漏。**

## 三、转折拍点

1. **开篇即反差（拍 1，0%–15%）**：两组数字并置，**不解释**——
   抽象件：`[成本]` ／ `[票房]`，或 `[历史峰值]` ／ `[当下值]`。
   关键：**第一句就必须是数字**，晚一行效果即衰减（本窗口 3 篇均如此）。
2. **数字→账本翻译（拍 3 前段，35%–45%）**：把"票房"换算成"谁分到多少"——
   抽象件：`按照片方分账，回本线是 [X] 亿起。`、`目前片方分账仅 [X] 亿。`、`回本线约 [X] 亿。`
   **这是本型的换挡器**：没有这一步，文章退化成票房播报。
3. **可复算的判定（拍 3 末，50%–60%）**：**承重句**——
   甲型 `现在看来是回本无望了。` ／ 乙型 `除去成本，小沈阳夫妇至少盈利5000万。`
   判定词是**确定性的**（"无望""至少"），区别于 `candidate-08` 那种**结论本身**带限定词的外推
   （"保守估计""大致推测"）。
   > ⚠️ **注意口径**：本型的**判定句**不许含糊，但**论证过程可以用反事实/虚拟语气**——
   > 10-10 原文就写着 `看了这两天的票房，要是《生化危机：爆发夜》没上的话，7亿或许还有可能实现。`
   > 把"不许限定词"推广到全文会写错（第 5 次执行独立复核对本条的更正）。
4. **`///` 后的补刀转折（拍 4，60%–80%）**：口碑账 / 前作账 / 行业账，
   把个案放进一个更大的账本：`对比当年《唐探》系列，还有《消失的她》等大爆款，简直扑得没法提。`
5. **落点（拍 5，80%–95%）**：**甲型是片方下一步**（把镜头从"这一部的账"推到"这个操盘方接下来要做什么"）；
   **乙′型是一句判词**（`这一块铜招牌算是砸了。`）。**两种都算合规落点**，区别见 §五。

## 四、情绪升级机制

```
账本冷启动（数字，无形容词） → 反差困惑（表面第一却亏损） → 翻译快感（原来是这样分账）
  → 判定落锤（回本无望 / 至少盈利 X） → 补刀（前作账 / 行业账） → 落点（下一步预告 或 一句判词）
```

关键三条：

- **快感来自"翻译"，不来自"骂"。** 本型的爽点是**把票房翻译成可复算的账**（`回本线是7亿起`），
  而不是形容词密度。窗口内 3 篇无一句重话。
- **判定必须先于补刀。** 补刀段只在**判定之后**出现；提到前面，读者就不知道该拿它算什么。
- **落点必须是"账的后事"**：要么给动作（片方下一步），要么给判词（招牌砸了）。
  `令人唏嘘` 这类**情绪收尾**不是本型（见 §六）。

| 核心动作 | 旧作财报 → 推算新作（**外推**） | 成本/回本线/落差 vs 实际（**对账**） |
| 判定性质 | **结论本身带限定词的推测** | **确定性判定**（回本无望 / 至少盈利 X） |
| 落点 | 固定互动三连 | 片方下一步动作 或 一句判词 |
| 段落分节 | `写在前面` 分隔符 | `///` 分隔符 |
| 篇幅 | 1000–1200 CJK（可读 3 篇） | 420–750 CJK（可读 18 篇） |

> **不建议合并**：合并会同时丢掉"外推必须带限定词"与"对账的判定必须可复算"两条互斥的红线纪律。

## 六、填充禁忌与边界

- **禁**：数字不核。成本、回本线、分账比例、票价、人次都是**可核事实**，写错即硬伤。
- **禁**：把"判定"写成"预测"。本型的判定是**对已发生账目的结算**；
  一旦写成"未来会怎样"，就撞进 `candidate-08` 的地盘，且**必须**在结论上加限定词。
- **禁**：只用票房、不做账本翻译。`总票房4.23亿` 是事实，`按照片方分账，回本线是7亿起。`
  与 `目前片方分账仅1.43亿` 才是本型的引擎。**没有翻译就没有判定。**
- **禁**：落点写成抒情。样本里的落点一律是**动作**或**判词**；`令人唏嘘` 不是本型。
  （本文件中"太让人心疼"只是**反面示例**，**样本里并不存在这句话**。）
- **禁**：把行业结构性困境塌缩成个人归因。写 `周星驰退出内地影院生意` 时必须同时给行业账
  （样本给的是 `2025年全国关闭约740家影院` 与 `七家A股院线半年报几乎全线亏损`），否则变成骂人。
- **禁**：成本数字来源不明时当确凿事实。样本自己写的是 `据传这部电影的制作成本是2亿。`——
  这类**必须保留"据传/据…"的限定来源**，不得洗成断言。
- **边界**：
  - 与 `candidate-06-参照系贬值体` 的区别——06 的参照系用于**贬值作品**；
    本型的参照系用于**对账**（拿历史高光账本作分母，算这一次亏多少）。
  - 与 `candidate-09-归因排除闭环型` 的区别——09 的引擎是**成因排除**（先承认公认解释、再用反证打掉、给出唯一机制归因）+ 恶性循环闭环；
    本型的引擎是**账本对账**，**不做因果排除**、**不闭环**。⚠️ 但 10-11 那篇**属于 09 而非本型**，
    划界时不要拿它当本型样本（这是本轮更正的口径）。
  - 与 `candidate-02-兴衰讣告体` 的区别——02 是**倒叙 + 三层归因 + 私人记忆收刀**（主体已"死"）；
    本型主体**仍在场**（还要"带来 [N] 部大片"），是**进行时**的账。

## 七、承重句清单（可直接迁移，均为抽象件；`[X]`/`[N]`/`[主体]` 为占位符）

1. `[成本 X]` ＋ `[票房 Y]` —— 开篇第一句，两组互斥数字，无形容词。
2. `按照片方分账，回本线是 [X] 亿起。` —— 数字→账本的翻译器（甲型的引擎句）。
3. `目前片方分账仅 [X] 亿。` —— 把"票房"降维成"到手多少"。
4. `现在看来是回本无望了。` ／ `除去成本，[主体] 至少盈利 [X] 万。` —— **判定落锤**。
5. `[历史峰值 A]` → `[当下值 B]`，中间用 `跌到` ／ `仅` 连接 —— 落差账的通用模板（乙′型）。
6. `[主体] 不甘心，又带来 [N] 部大片冲击市场。` ／ `[主体] 步履不停，又带来 [N] 部重磅大片。` —— 片方下一步收刀。
