### ⚠️ 自动规则不可单独采信（本轮实测）

→ 硬软文（购买 CTA）规则可靠（4/4 与人工一致）；**品牌软文必须人工通读裁定**。
完整两层判定（`kind_auto` / `kind_manual` / 不一致项）见
`runs/2026-10-14/macro-arch-weekly/02-selection-and-classification.json`。

## 二、伪装结构：7 拍推进表（供识别，非供模仿）

| 拍 | 篇幅占比 | 伪装动作 | 识别信号 |
| :--- | :--- | :--- | :--- |
| 1 | 0%–15% | **高质共情散文开篇**：名人轶事 / 童年记忆 / 电影史掌故 / 文化乡愁，**完全不提商品** | 开篇质量异常高，且与标题的消费点无关 |
| 2 | 15%–30% | **价值论证**：讲"这件事为什么重要"（文物之殇 / 拍片门槛之高 / 影评之难） | 通篇正确的公共价值陈述，缺少具体立场 |
| 3 | 30%–40% | **痛点压实**："可惜/然而/问题是"——让读者产生匮乏感 | 转折后不揭穿问题，而是引出解决方案 |
| 4 | **~40%（揭穿点）** | **救世主/答案登场**：品牌、公司、书籍、产品首次出现 | 句式：`如果你希望…强烈推荐…` / `聊了这么多，终于聊到 X 本身` / `谁能想到…` / `一间名为「X」的公司` |
| 5 | 40%–70% | **论据性质突变**：从叙事证据切换为**榜单 / 职衔 / 主创履历 / 参数 / 合作方** | 出现"权威机构排名""XX 前总裁""XX 大学学者评价" |
| 6 | 70%–90% | **稀缺性 + 价格锚**：原价 N → 现价 M；限量/绝版/错过不补 | 三件套：`限时` + `原价` + `赠礼清单` |
| 7 | 90%–100% | **行动号召** + 免责尾注 | `点击下图` / `—广告—` / `关注 X 好物查询订单` |

| 标签 | 判定（`kind_auto`，v2 规则） |

## 六、边界与例外

- **不是所有"荐书/荐片"都是软文**：若文章给出真实的取舍、缺点、不适合谁读，则属编辑稿。
  本规则的判据是**论据性质是否突变**与**是否存在对立证据**，不是"是否提到商品"。
- **转载稿 ≠ 软文**：`reprint` 与 `advertorial` 是两条独立的轴，需分别标注。
  转载稿的结构**可以**用于骨架提炼，但归因时必须写明转载来源（见 candidate-04 / 05）。
- **本 candidate 永不升级为可调用骨架**；它的生命周期终点是"并入选样过滤器与 L2 检查项"。

## 七、2026-W42 补遗新增：三类「不是软文、但同样不可用」的稿件

W42 只有一轴 `kind`，把下面两类一起并进了 `editorial`，会直接污染骨架提炼。
补遗轮把分类拆成三轴（`kind` 自动 / `form` 人工 / `stance` 人工），并明确：**本节三类只做人工判定，自动层不提供**。

| 类别 | 识别信号（人工） | 本轮样本 | 处置 |
| :--- | :--- | :--- | :--- |
| `recap` 剧情复述体 | 通篇复述剧情；"问句"是叙事设问（`为什么呢？` / `然后呢？`）；无编辑判断、无立场；长段落、短段比 ≈ 0 | 田田影视杂谭 ×4（836 / 852 / 915 / 921 CJK） | **不进骨架池**：它的"H2"是剧情节点，不是设问 |
| `listicle` 片单/书单导流 | N 部片 + 豆瓣分 + 金句 + 个人成长叙事 + 结尾书单/加星标/看更多 | 紫银看电影《一定要大量看电影…》（1234 CJK） | **不进骨架池**：结构是清单+导流，不是论证 |
| `weak_balancing` 弱立场双向收束 | 结尾两边都不站：`不必过度开心……也不必妄自菲薄`；承认 A 也承认 B，无判词 | Sir电影《诺奖诗人和《牛来》的缘分》（935 CJK） | **不进骨架池**；命中项目红线（`style_gate` 的 `stance:*` / L2 红线第 4 条"balancing-only = needs_changes"） |

### ⚠️ 本节最重要的一条：`recap` / `weak_balancing` **不可自动判定**（本轮实测）

用"观点词密度"（每千 CJK 命中数，词表含 `我觉得`、`其实`、`说白了`、`问题是`、`反而`、`可惜`、`遗憾`、`讽刺`、`所以` 等 26 词）实测：

```text
田田影视杂谭 4 篇复述稿：0.00 / 0.00 / 1.09 / 3.28
肉叔电影  深度编辑稿：1.76 / 3.42
Sir电影   弱立场稿  ：7.49（双向收束反而用词更密）
```

分布**完全重叠**——词表切不开复述体，也切不开弱立场（弱立场稿的观点词密度反而是全场最高之一）。
→ 结论：`form` 与 `stance` **一律人工通读**，自动层不得推断。这与 §三 对 `brand_soft` 的结论同源。

### 选样三问（替代"是否有编辑判断"的自动规则）

1. **这篇的二级标题/换挡句，是"论点推进"还是"剧情节点"？**（剧情节点 → 复述体）
2. **作者有没有一个可以被反驳的结论？**（没有 → 复述/盘点/导流）
3. **结尾是判词、闭环或具体批评，还是"两边都有道理"？**（后者 → 弱立场，命中红线）
