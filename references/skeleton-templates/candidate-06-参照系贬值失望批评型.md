# candidate-06 · 参照系贬值体（Benchmark Deflation）

> **状态**：`candidate`
> **首次沉淀**：2026-W42（2026-10-14）
> **适用题材**：剧评/影评中的"失望型批评"；高期待作品的落差评价；技术变量（AI/短剧/新工艺）冲击下的作品定位

## 二、H2 设问结构

**正文分节用技术性名词标题（如 `骗术` / `骗局` / `迷情`），全篇只有 1 处显式设问，在 15%–20%：**

```
今天在 <新变量> 里，这样的情节落地越来越容易了。
所以需要反问的是——<本类型>，到底能拍出什么不一样的？
```

要点：**设问把"评一部剧"升格为"评一种介质的存在理由"。**
这是本型的**抬价动作**：不设这个靶心，后文的失望就只是"我不喜欢"；设了靶心，失望变成"它没能证明自己值得存在"。

## 三、转折拍点

**两处，均为"先给期待再抽走"，但杠杆不同：**

| # | 位置 | 杠杆 | 抽象骨架 |
| :--- | :--- | :--- | :--- |
| 1 | 8%–20% | **外部参照系**（本可以做到） | `同类作品的下限是 X；而新变量已经能做到 Y。那么问题来了——你，凭什么？` |
| 2 | 48%–62% | **反转通胀**（给了也不值钱） | `第一层反转来了—— …… 第二层反转紧随其后—— …… 惊奇吗？一点都不。` |

**第 2 处的工程动作值得单独记住：**
先按"期待建立"的写法逐条列出反转（读者以为要夸），
再用一句四个字的否定（"一点都不"）**当场抽走全部价值**，最后给出原理标准（"悬疑的精髓在于藏"）。
→ 这也叫 **"先替读者期待，再替读者失望"**。

## 四、情绪升级机制

```
猎奇 → 智性满足（拆解）→ 被抬高期待 → 期待落空 → 层层失望 → 制度性愤怒（条条框框）→ 克制的遗憾
```

关键：**必须有一处"制度性证据"**（主创的公开表述、行业规则、创作约束），
把"演技差/剧本平"从**能力问题**升级为**结构问题**。
没有这一步，本型会退化为"骂演员"，寿命很短且易被判低质。

## 六、填充禁忌与边界

- **禁**：外部参照系选得空泛（"现在的剧都不行"）——必须是一个**读者承认的能力**（新技术/同期标杆）。
- **禁**：列举反转后不给出"为什么无效"的原理（否则读者以为作者只是看腻了）。
- **禁**：收刀只剩骂。本型要求**先承认下限，再列缺席清单**——承认下限是可信度的来源。
- **边界**：与 `candidate-01-诱饵反转体` 的区别——01 的杠杆在作品**内部**（最优片段的位置错配）；
  06 的杠杆在作品**外部**（本可以做到却没做到）。两者可叠加，但**同一篇里不要两次都用"先给期待再抽走"超过两回**，否则读者会识破全部套路。
