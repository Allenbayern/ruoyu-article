## 二、H2 设问结构

**本型不设二级标题，全部用内嵌短问换挡**，且**每个设问后面必须紧跟机制解释，不能跟抒情**。

| 位置 | 换挡设问 | 功能 |
| :--- | :--- | :--- |
| 拍 2 末（~30%） | `到底是谁的责任呢？家长有责，但是吹哥更想讨论另一个方面的问题……` | **承认对方 → 换到机制层**（本型的引擎句式） |
| 拍 3 末（~50%） | `为什么这个评价比满分还重要？` | 把表面事件升级为机制问题 |
| 拍 4 中（~65%） | `有人会说，内地申报了 39 次，但是提名只有 3 次……为什么这次就可以获奖了呢？` | **自我反驳式设问**：先把反例摆出来，再拆掉 |
| 拍 6（收尾） | `大家觉得呢？` | 互动收尾，非论证 |

> 与 `candidate-04`（双设问对照递进）的区别：04 的设问构成 H2 骨架（现象 → 成因 → 出路）；
> 08 的设问是**内嵌的换挡齿轮**，且方向固定为「承认对方 → 转到机制」。

## 三、转折拍点

1. **对撞转折（拍 2，~20%）**：两个互斥事实并置，不解释，让读者自己感到不对劲。
   抽象骨架：`A 说它满分，B 说它一星；分数 8.9，豆瓣 7.6。`
2. **个案→机制转折（拍 3，~35%）**：`家长有责，但真正的问题是……` / `吹哥真正关心的是……`
   —— 本型最关键的换挡句。**没有这一句，文章会退化成票房播报。**
3. **旧账→新账转折（拍 4，~60%）**：`参考 X 当年的财报/分账比例，算算这一部`
   —— 把历史数据当公式用。**转折的力度来自"算式可被读者复算"**。

## 四、情绪升级机制

```
数字好奇 → 互斥困惑（不对劲） → 机制揭穿（冷静的愤怒） → 算术快感（跟着算一遍） → 一句损话（松弛） → 互动收尾
```

关键两条：

- **快感来自算术，不来自形容词。** 三篇样本的高潮都是"算出来了"，不是"骂得狠"。
- **限定词必须留在结论上**：夜吹自己写的是"保守估计""大致推测""相信这个数只会少不会多""不敢保证一定能够获奖"。
  去掉限定词，外推就变成伪造事实——**这是本型最容易翻车的地方**。

## 六、填充禁忌与边界

- **禁**：数字不核。票房、分账比例、财报数字都是**可核事实**，写错即硬伤（本型的高可信度建立在数字上）。
- **禁**：外推不带限定词。`保守估计`、`大致推测`、`相信这个数只会少不会多` 是本型的合规件，不是软话。
- **禁**：只堆数字不过机制（退化成票房播报，无观点）。
- **禁**：把机制归因写成阴谋论（"故意淡化"必须有宣发物料证据，如 1157 靠的是海报/短视频卖点与片方策略的对照）。
- **边界**：与 `candidate-05-定义式行业观察体` 的区别——05 从"不是什么"的定义切入做分类枚举，**不含算术**；
  08 的杠杆是**可被读者复算的数字外推**。与 `candidate-06-参照系贬值体` 的区别——06 的参照系用于**贬值**，
  08 的参照系用于**推算**。
