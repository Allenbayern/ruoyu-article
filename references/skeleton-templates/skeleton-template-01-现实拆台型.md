## 一、骨肉分离：5 拍推进表

只保留无事实的结构推进拍点（与 README §一 规范一致，此处补入本周实证校准）。

| 拍 | 篇幅占比 | 叙事功能 | 微观写法调用 | 本周实证 |
| :--- | :--- | :--- | :--- | :--- |
| **拍点 1** | 0%–15% | **开篇夺魂**：以"我原本看轻它"的自嘲式降预期开场 → 弃剧 → 意外回看 → 顿悟式升维预告（"它聊的是一个时代"） | 切片卡【拍点一：开篇三秒夺魂】 | 肉叔：`我承认我小看了《余红旧事》。` / `看了几集后我就打住了。` / `可前两天，大概是实在没什么好剧可看，我鬼使神差地又把它捡了起来。` |
| **拍点 2** | 15%–35% | **假象立台**：先按旧框架讲一遍（以为是"又一个同类故事"），把表层体面/套路铺满 → 再亲手戳破（"但回头一想，又觉得不对劲——"） | 切片卡【拍点二：大白话拆台】 | 肉叔：`是不是很黑色幽默？` / `至少我在看的时候，好几次都笑出了声。` / `但回头一想，又觉得不对劲——` |

## 二、H2 设问结构

**本型用 `01 / 02 / 03` 编号分节，标题为名词短语；设问以内嵌短句承担，且必须落在"换挡点"。**

| 位 | 设问/换挡句 | 功能 |
| :--- | :--- | :--- |
| 拍 2 末 | `是不是很黑色幽默？` → `但回头一想，又觉得不对劲——` | 从"讲剧情"换到"质疑叙事方式" |
| 拍 2 末 | `那么它为什么拍成黑色喜剧？拍成《酱园弄》不行吗？` | 把疑问升级为**方法论疑问**（本型的引擎） |
| 拍 4 初 | `或许你会想——何以至此？怎么所有人都被逼到这份上？` | 从"人物"换到"时代"（**升维开关**） |

要点：**每个设问后必须紧跟一个新证据层**，而不是紧跟抒情。
`何以至此` 是本型最关键的换挡句——它一出现，文章就从人物批评转入结构归因。

## 三、转折拍点

**三处，均为"认知翻转"而非情节反转。**

1. **自我翻转（拍 1 末，约 15%）**：`我原以为 X，直到我看到 Y` → 把作者的误判当作入场券。
   抽象骨架：`我承认我小看了它。…我忽然意识到，它或许并不是讲述 X 那么简单。它聊的是一个时代。`
2. **叙事方式质疑（拍 2 末，约 35%）**：`这明明是 A，为什么被拍成了 B？` → 从内容转向形式批评。
3. **升维翻转（拍 4 初，约 60%）**：`何以至此？` → 个体责任让位给时代结构。

**承重句式**：`但回头一想，又觉得不对劲——`（把上一段刚建立的喜剧/体面感一次抽走）。

## 四、情绪升级机制

```
自嘲/好奇 → 荒诞好笑 → 笑不出来（自我否定）→ 沉重（逐个算账）→ 追问/愤怒（何以至此）→ 认命式悲悯 → 冰冷的安静
```

关键两条：

1. **必须先让读者笑，再收回笑的权利**（拍 2）：`至少我在看的时候，好几次都笑出了声。` / `但回头一想，又觉得不对劲——`
   —— 这是本型与一般苦难题材最大的差别：不靠铺惨，靠**剥夺读者已有的情绪舒适区**。
2. **收刀不许给安慰**（拍 5）：本型要求落在**静默的毁灭**上，不做和解、不做呼吁。
   肉叔的收刀句：`一直说着要活下去，却未必知道，自己会为此付出多少。又要别人付出多少。`

## 六、填充禁忌与边界

- **禁**：拍 1 只写"我以为不好看"，不写**为什么**看轻它（降预期需要理由，否则显得欲扬先抑的套路）。
- **禁**：拍 2 铺完假象却不亲手戳破（本型的核心动作是"自己推翻自己"，交给读者推翻就失效）。
- **禁**：拍 4 的"时代物证"必须是**剧中可指认的物/数/年号**，不能是作者的时代评论（会滑向议论文）。
- **禁**：拍 5 给希望、给呼吁、给金句式升华（本型收刀必须是**冷的**）。
- **边界**：与 `candidate-01-诱饵反转落差批评型` 的区别——本型批评的是**生存结构**，承重墙是"算账 + 升维"；
  candidate-01 批评的是**作品节奏**，承重墙是"诱饵 + 位置揭穿"。两者可写同一部作品（本周实证），但不可混用承重墙。
