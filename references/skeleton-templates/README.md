## 一、 模板架构规范（5 拍标准模型）

每套宏观骨架必须实现“骨肉分离”，仅保留无事实的结构推进拍点：

| 拍点 | 篇幅占比 | 叙事功能 | 对应的微观写法调用 |
| :--- | :--- | :--- | :--- |
| **拍点 1** | 0% - 15% | 开篇夺魂：反常动作 / 生死极端 / 悬念抛出 | 调用切片卡【拍点一：开篇三秒夺魂】 |
| **拍点 2** | 15% - 35% | 假象立台：人物表面体面 / 伪善规则交代 | 调用切片卡【拍点二：大白话拆台】 |
| **拍点 3** | 35% - 60% | 现实算账：不可抗力破局 / 切肤生存账本 | 调用切片卡【拍点三：切肤现实算账】 |
| **拍点 4** | 60% - 85% | 荒谬推演：撕碎退路 / 逼出底层动物性抉择 | 调用切片卡【拍点四：道具高潮】 |
| **拍点 5** | 85% - 100% | 冷酷收刀：微观道具定格 / 冰冷事实收束 | 调用切片卡【拍点四：冷酷收刀】 |

* **语料指纹的完整公式**（独立复核 round5 finding 2 的更正——原文缺了截断约定，照文档复算会误报"语料变了"）：

* **指纹的覆盖范围有两种口径，必须说清**（独立复核 round5 finding 9）：

  * 为什么要两套：**本轮的发现恰恰落在 v1 不覆盖的 12 条中短稿里**——只报 v1 的 0-delta
    会让人误以为"整个窗口都没变"。**报"逐字节相同"时必须写明是哪个口径**；
* 同一状态下的多次执行**全部可见**（同一 `run` 幂等跳过），把"同一窗口被触发 N 次"变成**可观测事实**；

## 三、选样铁律（2026-W42 实测新增，硬约束）

**纯 CJK 长度排序会把广告排到最前面。** 2026-W42 窗口按字数取头部 5 篇，其中 **3 篇是软文/PR 稿**、1 篇是转载，
**只有 1 篇**是对标号原创编辑稿（头部 8 篇中软文共 4 篇）。详情见 `candidate-07` 与 `weekly/2026-W42` §三。
因此本目录的选样流程**必须**内置体裁过滤：

1. 剔除硬软文（购买 CTA：`—广告—｜点击下图｜点击卡片｜即可购买｜去选购｜下单｜限时…价｜原价\d`）；
2. 剔除厂商 PR 稿（单一商业主体提及 ≥5 次 + 推广词典 + 无批评词）；
3. 转载稿（`转载来源｜本文转自`）可用，但**归因必须写明原始来源**，不得算作对标号自有方法论；
4. **本目录不产出传播结论**：微信采集索引无阅读量/点赞数据，依《爆款案例库》铁律，
   全部样本等级封顶 **C**——价值是"结构可复用"，不是"传播已验证"。

**2026-W42 补遗新增（第 5–8 条，均为实测）：**

5. **只按长度排序会漏掉"号内短文体"。** 长度头部全是长稿，而 `candidate-08`（夜吹电影，号内 12/21 复现）
   只有 1011–1157 CJK，在"只看头部长度"的口径下**全数落选**。
   → 选样改为**三路并行**：① 长度头部；② 排除体裁后的**中短稿**；③ **号内指纹扫描**（同账号 ≥2 篇复用同一套骨架）。
6. **体裁不止一轴。** 单看"是不是软文"会把 **剧情复述体**（无编辑判断）、**片单/书单导流**、
   **弱立场双向收束**一起放进"编辑稿"里，直接污染骨架提炼。三轴口径：`kind`（自动）+ `form` + `stance`（后两者人工）。
7. **"有无编辑判断"不可自动判定（实测）。** 观点词密度在"复述稿"与"深度稿"上完全重叠
   （田田影视杂谭 0.00–3.28 vs 肉叔电影 1.76–3.42），弱立场稿密度反而最高（7.49）。
   → `form` / `stance` **一律人工通读**，自动层不得推断；过滤清单见 `candidate-07` §七。
8. **注意采集时滞。** 窗口最后一天的对标号大稿，正文往往**还没进索引**（2026-10-15 窗口内 73 条有 26 条空正文）。
   定时任务 `0 4 * * 1` 会把"前一天的大稿"整批漏掉——这是口径问题，需 controller 裁决。
