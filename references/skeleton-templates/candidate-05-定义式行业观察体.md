## 二、H2 设问结构

**两节，一问命名、二问前途：**

```
H2-1：<新现象>实在精彩          ← 命名节（陈述句，充当"这是什么"的答案位）
H2-2：<新打法>，能救 <旧赛道> 吗？  ← 追问节（问句，把话题从描述抬到行业判断）
```

可选前置 H2-0（现象节，陈述句）。
要点：**命名节用陈述句、追问节用问句**——若两节都问，文章会显得没结论。

## 三、转折拍点

**没有情节反转；核心转折是"定义翻转"。**

工程化动作：把定义权从"是什么"移到"**不是什么**"。

抽象骨架：

```
如何定义这一批 X？我认为可以从它们"不是什么"入手。
首先，它们不同于曾经的 <旧类型 A> ……
其次，它们也不同于 <正统类型 B> ……
总之就是那句话：<A 固然重要，B 实在精彩>。
```

- 为什么有效：**排除法天然产生"边界感"**，读者会获得"我懂了"的确认。
- 代价：必须真的排除掉两个**读者确实会误解**的对象。排除稻草人（明摆着不是的）会立刻失效。

## 四、情绪升级机制

```
困惑（口碑崩）→ 了然（供需解释）→ 会心（一句反常识金句）→ 信息满足（分类枚举）→ 冷思考（行业归因）
```

关键：**枚举段是情绪高峰，但情绪来自"信息密度"而不是"故事"。**
本型不靠人物命运拉动，靠"分类越分越出格"的**梯度感**推动阅读。

## 六、填充禁忌与边界

- **禁**：排除对象选成明摆着的稻草人（"它不同于纪录片"）——必须排除读者真的会误认的类型。
- **禁**：枚举变成片单罗列（每类只挂作品名、不说明该类的关系结构）——那会退化成资讯稿。
- **禁**：结尾只给"值得期待"而不给行业层归因（本型的收刀是**冷判断**，不是推荐）。
- **边界**：与 `candidate-01 / 06` 的区别——01、06 是**作品批评**（对单一作品下判断）；
  05 是**行业观察**（对一类现象做分类学），不评判任何单一作品的好坏。
