## 二、H2 设问结构

**全篇仅 1 处显式设问，位于 25%–32%（倒叙授权点）：**

```
"XX 到底是怎么走到今天的？"
→ 自答："想理解 XX 的衰落，首先得明白——它曾经究竟有多牛。"
```

这个设问的关键功能**不是提问，是给自己的倒叙发许可证**：
没有它，读者会觉得"讣告里讲辉煌"跑题；有了它，辉煌段变成必需的前置。

三层归因**不用小标题切分**，用并列句与"当然…还不是…而是…"推进，保持"一篇文章一口气读完"的连贯感。

## 三、转折拍点

**无单点反转；改用"三层阶梯归因"。**

| 层 | 责任归属 | 递进逻辑 |
| :--- | :--- | :--- |
| 1 | 产品 / 策略失误 | 表面原因，读者最容易想到 |
| 2 | 人才 / 关系破裂 | "不过，要说最令人惋惜的，还不是第 1 层，而是…" |
| 3 | 资本 / 股权结构 | "当然，把一切归结于前两层，显然也太简单了" |

**每层的入口句都是"还不是…而是…"**——这是本型的承重句式：
它让归因看起来是**逐层深入**，而不是并列罗列。

---

## 四、情绪升级机制

```
震惊 → 唏嘘 → 怀旧自豪 → 愤怒（失误）→ 惋惜 → 温柔坠落（私人记忆）
```

关键：**收刀不是冷刀，是"私人化坠落"。** 从"1100 亿美元"坠回"一个人曾经看过的四个画面"。
这是本型与 README 5 拍模型最大的差异：5 拍要求"冷酷收刀"，本型要求**温情收刀**。

> 抽象句式骨架：`我之所以感慨，不是因为这家公司本身，而是想起很多年前……`

## 六、填充禁忌与边界

- **禁**：把"死亡宣告"放在标题之外的开头却迟迟不给量级锚（悬念会漏气）。
- **禁**：三层归因变成三块互不相干的罗列——必须共享同一个"本该做得更好"的标准。
- **禁**：收刀用行业术语（会毁掉"私人化坠落"）。
- **边界**：与 `candidate-03-边缘者正名体` 的区别——02 的主角是**组织**，03 的主角是**个人**；
  03 的设问是"为什么是他"，02 的设问是"它怎么走到今天"。02 的收刀落回**读者自己的记忆**，03 落回**被写者的身份**。
