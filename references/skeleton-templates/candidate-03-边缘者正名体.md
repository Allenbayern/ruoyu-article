# candidate-03 · 边缘者正名体（Vindication of the Unknown）

> **状态**：`candidate`
> **首次沉淀**：2026-W42（2026-10-14）
> **适用题材**：配角/替身/武行/幕后/外籍演员/龙套等"观众脸熟但叫不出名字"的人物；逝世/退圈/行业式微纪念稿
> **证据等级**：**C**（无传播数据，仅结构可用）
> **样本来源**：肉叔电影《那个总在港片里挨揍的洋人，走了》（何麦）2026-10-13，2271 CJK

## 一、骨肉分离：8 拍推进表

| 拍 | 篇幅占比 | 叙事功能 | 微观写法调用 |
| :--- | :--- | :--- | :--- |
| 1 | 0%–8% | **死亡通告**：日期 + 死因 + 享年 + 权威者定性（遗孀/同行发声） | 【拍点一：开篇三秒夺魂】冷启动 |
| 2 | 8%–15% | **主动降预期**："这个名字，很多人未必有印象""我也是才想起他是谁" | **反钩子** |
| 3 | 15%–20% | **钩子重估**："不过要是你喜欢九十年代港片，大概率在银幕上见过他" + 作品清单兑现 | 记忆点唤醒 |
| 4 | 20%–25% | **连续设问（全文引擎）**："为什么他的机会那么多？""为什么，他会一直'挨揍'？" | **H2 设问** |
| 5 | 25%–45% | **01 学艺史**：三段递进（出走 → 极短试炼期 → 长期苦功），中段安排一次生死意外抬升代价 | 【拍点二：大白话拆台】 |
| 6 | 45%–65% | **02 行业机制**（真正回答设问）：不是他特殊，而是**行业有系统性的需求**；引同行原话作证；再反证"他比别人多的是什么" | 【拍点三：现实算账】 |
| 7 | 65%–85% | **03 升维**：个人经历 → 时代/文化影响的缩影；**用"但 XX 却不一样。他没回去"制造分叉** | 升维 + 分叉 |
| 8 | 85%–100% | **收刀（身份反转）**：一个私人细节（守夜）→ "他在银幕上演了一辈子外人。但他，或许早已把自己当成了'家里人'了。" | 【拍点四：冷酷收刀】反转变体 |

## 二、H2 设问结构

**设问全部集中在开篇 25% 内，正文分节用 `01 / 02 / 03` 编号，标题为名词短语。**

```
开篇：为什么他的机会那么多？为什么，他会一直"挨揍"？
01 <学艺/成名前>     ← 回答"凭什么是他"
02 <行业机制>        ← 回答"为什么是他"
03 <时代升维>        ← 回答"他意味着什么"
```

要点：**问题前置、答案后置**，中间隔着 40% 的叙事。
这与"边问边答"的短平快设问相反——本型靠**问题悬置**撑完前半篇。

---

## 三、转折拍点

**两处，均为"分叉"而非"反转"。**

1. **中段分叉（约 65%–72%）**：所有同类人都离开了，**他没走**。
   抽象骨架：`这些来 X 的外国人回去之后，更是把火种传递了出去。……但 XX 却不一样。他没回去。`
2. **收刀分叉（约 95%）**：**称谓反转**——"演外人的人，把自己当家里人"。

两处分叉共享同一个母题（归属），构成首尾呼应。

---

## 四、情绪升级机制

```
平静（通告）→ 陌生感 → 好奇 → 敬佩（苦功）→ 理解（行业）→ 惆怅（式微）→ 一句话击穿（身份反转）
```

关键：**第 2 拍必须先"降低预期"再"唤醒记忆"。**
不降预期，读者会觉得"我又不认识他，凭什么看"；降了预期，"你其实见过他"才成为钩子。
这是本型最容易被漏掉、也最不可省的一拍。

## 六、填充禁忌与边界

- **禁**：跳过"降预期"直接吹捧（无名人物 + 高评价 = 读者无理由进入）。
- **禁**：02 节变成单纯的作品年表罗列——必须回答"**为什么是他**"（行业结构原因），否则只是资料汇编。
- **禁**：收刀用"致敬""怀念"等通用悼词（会抹掉身份反转的锋利）。
- **边界**：与 `candidate-02-兴衰讣告体` 的区别——02 主角是组织、收刀落回读者记忆；03 主角是个人、收刀落回**被写者的身份定义**。
