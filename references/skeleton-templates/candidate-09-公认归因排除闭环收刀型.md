# candidate-09 · 归因排除闭环型（Exclusion-Attribution with Feedback-Loop Close）

> **状态**：`candidate`（**单样本**，复现待验；本轮已做号内指纹扫描，仅 1/26 命中——见 §五）
> **首次沉淀**：2026-W42 补遗（2026-10-15）
> **适用题材**：行业性坏消息的**成因批评**——档期崩盘、类型失灵、市场寒冬、审美退化、平台生态恶化
> **证据等级**：**C**（无传播数据，仅结构可用）
> **样本来源**：独立鱼电影《今年国庆档，彻底崩完了！》2026-10-09，1831 CJK
> **适配篇幅**：1500–2500 CJK；本型需要"排除-反证-个案-闭环"四段，太短则兜不住

## 一、骨肉分离：7 拍推进表

| 拍 | 篇幅占比 | 叙事功能 | 微观写法调用 |
| :--- | :--- | :--- | :--- |
| 1 | 0%–10% | **量级崩塌开场**：一个数字 + 一个历史对照 + 一句崩溃判定，三段短句连砸 | 【拍点一：开篇三秒夺魂】 |
| 2 | 10%–22% | **公认归因陈列**：把公众的 2–3 个解释逐一摆出（"有人会说……也有人说……还有人怪……"），并**先承认它们"都有一定道理"** | 假意公平（诱敌） |
| 3 | 22%–30% | **换挡否定 + 唯一归因**：`但鱼叔觉得，都没有说到最根本的问题` → `不是 A，而是 B`（B 必须是可被追问的机制命题，不是情绪） | 【拍点二：大白话拆台】 |
| 4 | 30%–42% | **反证数据**：拿一个数据把这个"最流行的解释"当场打掉（本例：票价降了，观众还是没来） | 反证装置（本型的物证） |
| 5 | 42%–75% | **个案解剖**：取当期最受期待的样本，先抬高（原型/班底/预期），再用三层具体批评把它拆开 | 【拍点四：道具高潮】批评变体 |
| 6 | 75%–85% | **升维判断**：给一句可被引用的行业判断（逐字原文：`所谓黄金档期，从来不是电影的救命药` / `它只是好电影的放大器`） | 金句位 |
| 7 | 85%–100% | **闭环收刀**：把前文全部归因接成一条自我强化的循环链，最后一句收在"越……越……" | 【拍点四：冷酷收刀】 |

## 二、H2 设问结构

**本型不设编号标题，靠"转述式设问 + 短问换挡"推进**——设问的作用是**替读者把反驳说出来**，再拆掉。

| 位置 | 换挡设问 | 功能 |
| :--- | :--- | :--- |
| 拍 4 初（~35%） | `结果呢？` | 最省字的换挡器：上一段说"降价了"，这一句直接调出结果 |
| 拍 5 初（~45%） | `可今年国庆档，又有几部电影，敢拍着胸脯给出这个承诺？` | 把抽象标准转成可数的追问（承诺 = 那两个小时值得） |
| 拍 7 初（~88%） | `如果一部新片，连上映几个月的老片都竞争不过，那问题真的能全部归咎于消费环境吗？` | **闭环开关**：把第 2 拍的公众归因重新拎出来，用新证据反打 |

> 与 `candidate-05` 的区别：05 从"**不是什么**"的定义切入；09 从"**不是因为这个**"的排除切入。
> 05 的骨架是枚举，09 的骨架是**排除 + 反证**。

## 三、转折拍点

1. **假意公平 → 一次否定（拍 2 末，~22%）**：先承认对方"都有一定道理"，再一句"都没有说到最根本的问题"。
   **力度来自承认得足够诚恳**——如果开篇就否定，读者不会跟着走。
2. **流行解释被反证打掉（拍 4，~40%）**：`票价降了，观众还是没回来` ——
   本型的**硬转折**。没有这个数据，第 3 拍的"唯一归因"只是作者态度。
3. **个案不背锅的转折（拍 5 末，~70%）**：`今年国庆档的惨淡，不能怪《神探之痕迹》` →
   把批评从一部片移到整个档期，完成**个体 → 结构**的升维。
4. **闭环转折（拍 7）**：求稳 → 无新意 → 不买票 → 不敢冒险 → 更求稳。

## 四、情绪升级机制

```
震惊（数字崩塌） → 不服（公认解释都不对） → 冷静反证（数据说话） → 具体愤怒（好题材被浪费） → 悲凉（恶性循环闭合）
```

关键两条：

- **愤怒必须落在具体处**：本例的怒火全部砸在"案件串烧 / 亲情线没挖 / 电视剧感"三个可指认的技术问题上，
  不写"导演不行"这类人身判断。
- **收刀必须是闭环，不是呼吁**。本例结尾没有任何"希望行业……"的呼吁，
  只有一句**因果链自证**：`行业越害怕失败，就越难创造真正的成功`。

## 六、填充禁忌与边界

- **禁**：归因不可被追问。`不是观众不愿意看电影了` / `不值得观众专门去看了` 之所以立得住，是因为下一段立刻给出了可核反证（降价无效）。
  只给"不是 A 而是 B"却没有物证的，是情绪文，不是本型。
- **禁**：把公众归因写成稻草人。必须写出对方真实的解释（本例三个：大环境/短视频分流/票价贵），不能一句话带过。
- **禁**：个案批评滑向人身攻击（见 §四）。
- **禁**：结尾写呼吁。本型的收刀是**因果链闭合**，不是"希望行业振作"。
- **边界**：与 `candidate-02-兴衰讣告体` 的区别——02 有一根**倒叙时间轴**（先判死 → 回望辉煌），
  09 只有**当下**（不回溯历史）；与 `candidate-03-正名体` 的区别——03 的收刀是身份反转，09 的收刀是机制闭环。
