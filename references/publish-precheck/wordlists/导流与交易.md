# 导流与交易词库（词库通道，非正则）
#
# 第三方 `wordlists/` 通道与 `../my-rules.md` 黑名单的语义不同（上游 `scan.py:137-165`、`:215-232`）：
#
#   # 通道                      # 写法                            # 匹配        # 门控  # 档位
#   # my-rules.md 黑名单        # 正则                            # re.compile  # 无    # 每行自带
#   # wordlists/*.md | *.txt    # 纯字面词（re.escape）           # 字面子串    # 无    # 固定「中」
#
# 所以这一层放的是**不需要正则能力、又不该被"商业属性"门控**的字面词。
#
# 存在意义（2026-10-16 第 13 轮复核更正过口径，别按旧版读）：
# 官方 `commercial-expression.R05`（站外引流元素：加微信/进群/扫码/看主页/链接/电话…）
# 是 `commercial_only=true` —— 单篇声明为非商业时，**R05 这一面的导流动作**不报；
# 而今日头条的"交易相关风险"是**账号级**的，不随单篇非商业而消失（见 runbook §12.1 实测）。
#
# ⚠ 但**不是**「非商业档联系方式面全盲」：官方 `general-community-safety.G09`（隐私与个人信息）
# 是 `commercial_only=false` / `severity=critical`，pattern 含 `手机号|微信号`（无条件生效）。
# 所以 `微信号`/`手机号` 这种字面词**零边际检出**（G09 已无条件覆盖且档位更高），本库**不收**。
#
# 只盯作者对读者发出的**动作/界面形态**，不收剧情·行业转述里的现象词。入选判据（全部满足）：
#
#   1. 自有语料 0 命中（本次复算：220 文件 / 365,232 字符；数字随 runs/ 增长会漂移）；
#   2. 对照语料 0 命中（154 文件 / 652,086 字符）；
#   3. 不是常用词的子串（`威信`＝"威信扫地"、`扣扣`、`引流`、`变现` 一律**不收**）；
#   3b. 只收动作/界面形态，**不收行业·题材现象词** —— `一手货源`/`带货佣金`/`招商加盟`/`秒杀`/
#       `拼团`/`拉人头` 等虽然两语料也 0 命中，但剧情与行业转述里会出现，与判据"只盯作者动作"冲突；
#   3c. **不重复官方已无条件覆盖的面**（G09 覆盖联系方式字面词，见上）；
#   4. 与我们自己的定稿排版规范不冲突（**不收**「关注 / 在看 / 蓝字 / 点击上方」族 ——
#      文末关注大卡本身就写「👉 点击顶部蓝字关注『若雨随影』」，收了等于每篇自报违规）。
#
# 候选清单与逐词计数留档在 `scripts/publish_precheck_wordlist_mine.py`（75 个候选 / 4 组，
# 本次取其中 37 个），可随时复算：`.venv/bin/python scripts/publish_precheck_wordlist_mine.py`
#
# 注意：本文件里**只有下面每一行是词条**，其余每行都以 `#` 开头（上游把 `#` 行当说明跳过）。
# 词条格式：`词 | 原因`（也支持 TAB 分隔）；匹配是**字面子串 + 大小写不敏感**，不解析正则。
