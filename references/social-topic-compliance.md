## 三态总原则

每道门与总等级使用 `PASS | CONDITIONAL | FAIL`。`PASS` 可按常规候选流程继续；`CONDITIONAL` 不是自动放行，只有推荐 `A/B/C` 时才必须附带非空、可追溯的 `compliant_angle` 与具体写作约束，且仍需人工编辑判断、来源/事实核验和逐项控制。`FAIL` 不得推荐 `A/B/C`，但可以 `Archive | Reject | Wait` 留档，不连坐整池。

总等级优先读取 `five_gates.overall`；仅在其缺失时兼容旧 `five_gates.result`。硬红线保持 `FAIL`，不得通过改写或表述替换降级。

## 2. 五道门判定细则

### 门 1：新闻资质

**核心逻辑**：普通个人号无互联网新闻信息服务许可，不得以新闻报道形态发布社会公共事务/社会突发事件。

**判定问题**：
- 核心信息是否属于「社会公共事务/社会突发事件的报道评论」？
- 事件来源：个人亲历/自行采访 vs 媒体独家报道/转述？
- 文章形态是「我来报道这件事（时间/地点/人物/经过/调查细节齐备）」还是「围绕公共话题做制度观察/生活评论」？

**红线信号**：
- 以完整新闻稿结构（导语→时间线→各方反应→专家观点→结尾）复述他人报道的社会事件
- 堆砌精确时间、地点、医院/机构全称、函件/鉴定细节
- 转写媒体「独家调查」型报道 → 本门 + 门4 双风险

**安全写法**：
- 开头明确「据 XX 报道（媒体名+日期）」，来源醒目
- 文章主体是评论/观察/科普，事件只作引子（事件部分 ≤ 全文 1/3）
- 不出现独家细节堆砌

### 门 2：个人隐私

**核心逻辑**：普通人的隐私非必要不披露。当事人不是公众人物，其疾病、婚姻、家庭经济、亲子鉴定等细节不构成公共信息。

**判定问题**：
- 文中出现哪些当事人信息？（姓名、住址、职业、疾病、抑郁、婚姻、子女、经济、亲子鉴定、出生细节…）
- 这些信息是「理解事件必需」还是「增强戏剧性/博取关注」？
- 删掉后文章还剩多少价值？（若无价值 = 题材本身不成立）

**红线信号**：
- 普通人（非公众人物）的疾病/抑郁/婚姻/亲子鉴定/家庭经济 = 非必要细节，删
- 具体出生时刻、住处距离等可定位信息 = 删
- 当事人未经授权的生活照/病床照/鉴定文件截图 = 不配
- 用了化名却不标注「当事人姓名为化名」 = 违规

**安全写法**：
- 只留事件骨架（何地、何时、何因、现状）
- 当事人一律化名 + 明确标注
- 删除一切与论点无关的私密细节

### 门 3：司法状态

**核心逻辑**：未决案件不得预判责任。因果链不得写满。

**判定问题**：
- 案件是否已有生效判决？
- 文中是否有责任归属的确定性表述（「错抱」「医院失职」「某方有错」）？
- 是否把「当事人主张」写成了「事实认定」？

**红线信号**：
- 未决案件不得预判责任
- 因果链不得写满（「错抱导致肝癌」✗ → 「法院认定医院存在重大过错；肝癌成因复杂」✓）
- 「完全可突破时效」类法律观点必须标注出处（专家/代理律师观点），不得写成事实

**安全写法**：
- 全部用「当事人称 / 医院回应 / 法院已受理 / 责任有待法院审理」
- 当事人主张、专家观点、法院结论三者明确区分

### 门 4：版权来源

**核心逻辑**：未经授权不得使用他人享有著作权的内容。

**判定问题**：
- 事件信息来自几个来源？是否单一媒体独家调查？
- 我的叙事结构、细节、引语是否与某篇报道高度重合？
- 我是否获得授权/自己采访过？

**红线信号**：
- 结构+细节+引语与在先作品实质相同 = 洗稿
- 无自行采访的独家调查转写 = 高风险
- 实质为改写却勾选「原创」 = 违规

**安全写法**：
- 多来源交叉（官方通报 + 多家媒体报道）
- 醒目标注来源与日期
- 用自己的评论角度组织，不逐段复述
- 未获授权不勾「原创」

### 门 5：猎奇风险

**核心逻辑**：平台不鼓励靠堆砌异常数字、悲惨细节制造话题。

**判定问题**：
- 选题吸引力来自「事件的悲剧/离奇/异常数字」还是「制度的反思/公共讨论」？
- 是否密集排列悲惨细节？
- 标题是否靠耸动数字/夸张反差制造点击？

**红线信号**：
- 异常数字堆砌（55分钟/37年/5公里）= 猎奇信号
- 标题与内容不符 = 违规（标题失真）
- 反复消费同一当事人苦难 = 高风险

**安全写法**：
- 标题用制度问题/公共议题，不用耸动数字
- 正文不堆悲惨细节
- 关注「为什么会发生、如何避免」，而非「这件事多惨」

## 4. 低风险改写模板

### 标题（30字内，含信息密度）

- 「从一桩错抱争议看，新生儿身份核验为何需要多重确认」
- 备选：「1989年同院出生，2025年DNA揭开两名女子身世」（26字）
- 备选：「两名女子36年后确认身份错位，医院称等待法院判决」（24字）

### 开头模板

> 据中国新闻周刊8月1日报道，两名1989年在清远市人民医院出生的女子，经司法鉴定确认生物学亲缘关系与各自的抚养家庭不一致。两名当事人已起诉医院，医院回应称案件正依法依规处理，责任认定有待法院审理。文中当事人姓名为化名。

### 正文结构（5段）

1. **150字事实 + 时间线**（只陈述已核验事实，来源醒目）
2. **100字双方诉求与医院回应**（当事人称/医院称，不含预判）
3. **制度层**：2014年国家卫生计生委腕带/交接登记制度及背景
4. **隐私最小化讨论**：身份核验为何需要多重确认（评论角度）
5. **收束**：以法院公开审理结果为准（不预判、不猎奇）

### 改写纪律

- 不勾「原创」（除非符合平台原创标准且获授权）
- 必须醒目标注来源（「据中国新闻周刊8月1日报道」）与「当事人姓名为化名」
- 删除疾病、婚姻、家庭经济等非必要隐私
- 不配当事人未经授权的生活照、病床照、鉴定文件截图

## 5. 因果表述纪律（姚策案教训）

### 错误
> 「因错抱导致姚策未能及时接种乙肝疫苗，后罹患肝癌去世」

→ 因果过满。错抱、乙肝疫苗、肝癌之间的因果关系并非单一链条，且已有司法判定。

### 正确
> 「河南'错换人生28年'案中，法院认定医院在管理、病历和乙肝疫苗接种方面存在重大过错；同时指出肝癌成因复杂，最终判令医院按相应比例承担损失。」

### 原则
- 不可写「错抱导致肝癌」
- 涉及医学/法律因果关系的断言，必须引用裁判文书或权威机构声明
- 不确定的因果链：用「存在关联 / 争议焦点 / 有待进一步认定」

## 7. 四类社会热点分类判定路径

不同选题类型，五道门的权重和判定重点不同：

### A 型：官方新规 × 普通人生活
- 新闻资质：低风险（不涉及突发事件报道，是制度解读）
- 主要关注：门4（参考哪些官方文件/媒体报道？需标注来源）
- 其他门：通常低风险

### B 型：消费/旅游/网络平台现象
- 新闻资质：中风险（如涉及具体事件/投诉个例）
- 主要关注：门2（是否披露具体消费者隐私）、门4（来源标注）
- 高价值角度：从个例上升到普遍现象讨论

### C 型：公开数据反常变化
- 新闻资质：低风险（数据属于公开信息）
- 主要关注：门4（数据来源标注）、门5（避免耸动标题）
- 高价值角度：数据背后的制度原因/社会变化

### D 型：影视/文旅/互联网跨界热点
- 新闻资质：中风险（如涉及具体争议事件）
- 主要关注：门3（是否涉及未决争议）、门5（避免猎奇化）
- 高价值角度：行业现象/文化趋势讨论

### E 型：已有明确处理结果的公共事件
- 新闻资质：中风险（仍属社会公共事务，非新闻报道形态）
- 主要关注：门3（已判≠可随意归纳因果）、门4（来源标注）
- 高价值角度：制度反思/生活评论

### 343斤网红事件
- 分类：涉及普通人健康、身体特征和争议行为
- 判定：偏高风险（门2 隐私 + 门5 猎奇 + 禁区「普通人身体特征」）
- 用户明确：**暂不发布**
