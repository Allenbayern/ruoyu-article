## 卡片 A：选题筛选卡（粥左罗）

**选题三问（过一票否决线）**

1. 覆盖人群有多大？（谁会点进来，是不是"老百姓向"）
2. 痛点有多强？（读者不看会损失什么：谈资、认知、情绪出口）
3. 社交原动力是什么？（读者转发的理由：显摆新知 / 找同类 / 表达立场 / 送温暖）

**选题五技巧（找题灵感轴，五选一以上）**

- 痛点：戳中当下普遍的难受（职场、亲密关系、代际、育儿）
- 共鸣：说出"原来不只我这样"
- 身份认同：帮一类人说出身份宣言（打工人/宝妈/小镇青年）
- 热点势能：借当天热榜的讨论窗口，文章给出增量
- 新知：给出读者没听过的事实、机制或解释

**好文章五标准（成稿自检）**

新知、信息密度、逻辑、易懂、真诚——缺"新知"和"信息密度"的稿子属于
`evidence_summary_disguised_as_article`（见 playbook §3.3），应补场面/机制或退回选题。

**选题动作：发现平淡日子里的刺**

在人人习以为常的现象里找"不对劲"：剧名为什么越起越像、配角为什么比主角更让人
惦记、老剧为什么今天突然被翻出来。落点是现象背后的人物处境或集体情绪，不是
现象罗列。

> 落地：三问/五技巧映射到本组候选卡五问检查表（读者/落点/情绪/删节点测试/
> 社交原动力）。当前以手工清单执行；是否进 candidate-card 必填字段与
> portfolio_gate/preflight 门禁，待 controller 决定（见 §落地与待办）。

## 卡片 B：选题公式卡（无量仙翁模式）

**公式：热门作品 × 空白角色 × 集体情绪**

- 热门作品：已经有大规模讨论、热度可查证的当季内容；
- 空白角色：作品热、但没人深写的角色或角落（配角、反派、被忽略的支线）；
- 集体情绪：这个角色身上能挂住一类现实情绪（野心、委屈、不被看见）。

**实战（daily-007 art-001）**：《兰香如故》热播期，热榜讨论杜翠雀"有心机/野心
女子图鉴"，无人深写她为什么让人恨不起来 → 落点"又气又讨论"的集体情绪。
同作品已在 daily-001 写过开播角度时，须以"不同人物+不同问题+热播期新数据"
记录实质新角度（portfolio_gate 黄灯解释口径）。

## 卡片 C：起稿结构卡（SoPilot 五母结构）

**总公式**：明确收益 → 旧认知为什么不够用 → 新框架 → 3-5 个推进段落 → 可传播结尾

**5 种母结构（每篇只挑一种做主结构）**

| 母结构 | 公式 | 适合题材 |
|--------|------|---------|
| 情绪顿悟型 | 具体场景 → 误判/惯性理解 → 一个瞬间被击中 → 新认识 | 人物处境、关系冲突、成长观察 |
| 立场宣判型 | 先下判断 → 解释为什么多数人看错了 → 逐层论证 → 行动含义 | 反常识观察、文化现象判断 |
| 身份解放型 | 你以前做不到 → 现在为什么能做到 → 怎么上手 → 做到后意味着什么 | 工具/方法论（本组少用） |
| 系统方法型 | 你努力没结果 → 问题不在努力而在方法设计 → 新系统 → 分步骤 | 方法论拆解（本组少用） |
| 低门槛实用型 | 结果承诺 → 为什么比想象简单 → 步骤交付 → 补充场景 | 清单/收藏向（本组少用） |

本组两篇日用情绪顿悟型与立场宣判型：影视话题落到人物处境与关系冲突，天然适配。

**6 条硬规则**

1. 开头 3 段内交代阅读收益（不铺长背景）；
2. 一篇只打一个主承诺（不混观点+教程+故事+案例）；
3. 中段每节推进：旧理解哪里错 / 新框架是什么 / 具体怎么做 / 为什么现在值得；
4. 多用具体名词（人、作品、动作、场景），少写"很多人""一些问题";
5. 正文自然长出可引用句（金句用大白话，不堆成语）；
6. 结尾不泄气：清晰判断 / 可执行动作 / 可记住的新说法。

> 落地：硬规则 3/4 已对应 playbook §3.3 的"每段新增事实/场面/机制或判断"与
> `article_mode` 文体边界；规则 1/2/5/6 作为读者面写法清单手工执行。

## 卡片 D：标题包装卡（SoPilot 标题公式）

- 判断型：`为什么 X 其实不是问题，真正的问题是 Y`
- 收益型：`如何用 X 在更短时间里得到 Y`
- 反常识型：`多数人以为 X 更重要，但真正决定结果的是 Y`
- 关系/人生型：`当 X 发生以后，我才意识到 Y`

> 落地：本组规约是"标题在正文之后包装"（playbook §2）——公式只在包装阶段提供
> 候选形态，每条标题仍须绑定正文 locator 与来源 locator，走 title_pack/title-pack-
> review 流程；标题要求与正文承诺一致（task-card fidelity 门禁）。

## 卡片 E：行文语感卡（口播结构库，抖音/快手观察）

**开头钩子（前 3 秒/前 2 句话，选 1）**

1. 反常识断言；2. 直问戳心（"你有没有发现…"）；3. 场景代入（具体时间地点动作）；
4. 数字/清单预告；5. 先抛金句；6. 反向输出/揭秘；7. 共鸣陈述。
禁用慢热套话开头（"今天给大家分享…""在这个快节奏的时代…"）。

**正文框架（选 1）**：观点-故事-升华 / 正反对比 / 三层递进 / 排比破局（排比≤2段，
第三句换散句）/ 场景连拍 / 情绪弧线（平淡→爆发→收敛留白）。

**收尾（选 1）**：升华金句 / 互动提问 / 行动暗示 / 留白。

**表达特征（书面文借鉴部分）**

- 短句为主，单句尽量 ≤20–25 字，允许半句话；
- 多用口语词（其实、真的、说白了、你发现没），少书面连接词（然而、此外、综上所述）；
- 多用"你"，少用"我们大家"；
- 具体细节大于抽象概念（不写"很辛苦"，写"凌晨两点还在回消息"）；
- 金句密度：约每 60 秒/600 字 1–2 句，大白话。

> 落地：书面文不搬"算法参数"与平台禁忌表，但钩子/框架/收尾与短句口语化可作
> 读者面语感清单；本组 style_gate 的红线（自证/元话语/读后感腔）与这里的
> "坏开头"清单方向一致，实际执行以 style_gate 为准。
