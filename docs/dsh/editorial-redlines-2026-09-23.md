## 逐条口径

### 1. 公关和稀泥腔 = error（不是 warning）

命中即本地打回，不进复核。理由：没有立场的稿子读者站不了队。

**例外（实测修正）**：免责/辩护类句子若"归因在前 + 反驳在后"，属于报道对立面，
不判错。成稿的周也重写篇正是这个形态：

```
……辩护的核心逻辑是"人在极度压抑时本就会哭得难看，这是角色的特定处境"。
但这套辩词完全无法平息普通观众的不满。
```

只有"归因"、没有"反驳"的（`替她说话的人理由也硬，她情有可原。`）仍然判错——
那正是被否稿把辩护当结论的写法。作者自己的框架句（`谁也说服不了谁`、
`两边都有道理`）永不豁免。

### 2. 字数下限 1500（取代 2026-09-16 的下限口径）

- `TARGET_MIN_CJK_CHARS = 1500`（不变）、`MIN_CJK_CHARS = 1500`（原 900）；
  上限维持 2800。弹性只保留在上限侧：下限弹性会让薄稿重新溜过门禁。
- **反灌水原则不变**：扩写必须来自横向维度（历史对照、同侪反差、行业机制、
  一手材料）。素材确实撑不到 1500 字时，由 `RunProfile` 的
  `min_cjk_chars` 字段或 controller 显式放宽，而不是让门禁沉默放行。
- 这条**取代**了 2026-09-16 的"下限 1000→900、篇幅以素材为准"下限口径；
  上限侧的 ±100 弹性与反灌水精神不变。controller 若要恢复旧下限，
  改 `run_profile.py` 两个常量并把 `tests/test_run_profile.py` 的断言改回即可。

### 3. `killer_stance`：可选性为零，和稀泥一票否决

`candidate-pool.json` 的每个候选新增必填字段 `killer_stance`（≥12 CJK 字），
并进入 `_CANONICAL_SLOT_FIELDS`，因此槽位合同与后续漂移检查都会锁住它。

自检三问（写进字段内容里）：**靶子是谁？极端反差是什么？给读者什么确定性结论？**

以下写法在 `validate_candidate_pool` 阶段直接报错：

- `both_sides` 两边都有道理 / 双方都有道理
- `subjective` 见仁见智 / 仁者见仁
- `each_own` 各有各的…
- `two_sided` 两面性 / 双刃剑
- `both_and` 既…又…
- `explore_only` 只有"探讨…背后的"
- `excuse` 情有可原 / 不能全怪 / 不可全盘否定

### 4. 感官锚点与抽象腔

两侧同时落地：

- **声明侧（硬）**：`evidence-pack.json` 可声明 `sensory_anchors`
  （例：`["屏风暗室","解开衣带","雨夜寺庙"]`）。声明了就必须在正文逐条出现，
  否则 `validate_article_stage` 报
  `article_<aid>_sensory_anchor_<i>_not_in_body`；声明少于 3 条报
  `..._below_minimum_<n>_3`。未声明时不报错（历史批次不追溯）。
- **自测侧（软）**：`style_gate.sensory_anchor_check` 在稿件自测阶段统计
  "抽象评述词（契约/让渡/界定/机制/结构性…）"与"具象物理锚点（撕/剪/咬/
  灵位/衣带/雪/雨夜…）"，抽象词 ≥6 且锚点 <3 时告警，提示读者抓不到画面。

### 5. L2 五条内容红线（`L2_CONTENT_REDLINES`）

每次 L2 复核 prompt 自动携带，未背书即阻断：

1. **引语真实性**：带双引号的网友/业内人士/当事人长句＝一手发言，
   账本给不出可回读原文即 blocker，改间接转述。
2. **时代/道具常识**：古装民国题材不得出现跨时代器物（实例：古装武侠角色
   被写成"中枪身亡"）。
3. **代言心理**：无一手材料不得替演员/主创陈述内心动机（实例："试图通过
   咬牙切齿…拼命够到对方的气场"），改为可观察的外部描述。
4. **立场**：只平衡两边或只替一方辩护、给不出可被否证的判断＝needs_changes。
5. **账本↔正文同步**：声明的感官锚点与数字断言必须在成稿可见；
   全篇抽象、无具象锚点＝needs_changes。

## 已知边界（不夸大成"已解决"）

- **正则覆盖不到"更隐蔽的和稀泥"**：被否 v2 用"这套辩词无法平息不满"的写法绕过了
  立场正则。v1 抓住了、v2 没抓住——所以第 3 条（立项阶段定立场）才是主防线，
  正则只是兜底。这条边界不隐藏。
- **归因豁免是启发式**：40 字窗口 + 标记词表，长句改写可能误判；豁免只作用于
  "免责/辩护"五个标签，硬和稀泥标签不受影响。
- **感官锚点是词表统计**，不是语义理解；它只能提示"读起来抽象"，不能判断某段
  抽象论述是否真在干活，因此永远是 warning。
- **字数下限是编辑取舍**：门槛提高会逼出扩写，也可能逼出注水。发现注水应按
  反灌水原则退回，而不是把下限再降回去。
- 本次未改 Vault canonical；若 controller 要把它升级为跨项目规则，需要按
  Vault 写回协议单独授权。
