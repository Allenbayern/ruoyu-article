## 2. 五项标准操作规范（SOP）

### SOP-01 标题敲定后的【二次定向补网检索】（“定题即定检”）
- **痛点**：前期初搜仅解决“这道题能不能写、有哪些通用事实”，材料广而散；一旦标题被 controller 拍板，文章的核心叙事承诺（Title Promise）已锁死在标题的特异性词眼上。如果直接动笔，细节往往泛泛而谈、流于空洞。
- **强制规则**：
  1. **锁定最终标题不能作为“立刻动笔”的触发器，而必须作为“启动微观定向检索”的触发器**；
  2. 针对标题中的核心动词（如“肉眼锁定”）、核心专有名词（如“白宝山案”）展开二次针对性深挖；
  3. 捕获到一手微观物理事实（如“显微镜下反射光角度”、“抛壳挺右下角微米横线”、“16天连打3000发实弹”）后，方可进入正文写作。

### SOP-02 标题候选生成规范：【30字物理截断检查】与【大白话动作白描】
- **痛点**：
  1. 标题字数若超限，在移动端微信订阅号消息列表中会被 `...` 强行截断，丢失末尾的核心收力点；
  2. 容易出现行业/方言黑话与缩写（如“2年抱3”、“23岁止损”），产生认知门槛；
  3. 复合标题容易出现前后主谓脱节（如前半句写罪犯，后半句主语切到警察）。
- **强制规则**：
  1. **物理字数闸门**：标题输出前，必须严格计算字符数（全角中文+标点 **≤ 30 字**），杜绝事后强删破坏语感；
  2. **主谓一致性审查**：复合标题前后两截的主语必须指向明确统一；
  3. **动作白描审查**：坚决剔除“止损”、“对冲”等分析型冷词，强制转换为普通读者一秒脑补的具象白话动作（如“23岁带着3个儿子离开豪门”）。

### SOP-03 外部投喂参考材料的【逆时差降维吸收法】
- **痛点**：用户经常提供往年深度报道或自媒体爆款链接（如知乎文、历史特稿）。如果全盘照搬会陷入过时结论，如果弃之不顾则浪费优质事实拼图。
- **强制规则**：
  1. **第一步（提取事实切片）**：抓取文章中的客观物理事实与历史背景（如梁洛施原生家庭私生女创伤、加拿大独居汉堡店、前7年拍戏受家族审视）；
  2. **第二步（审视时空局限）**：标注原文发表年份（如2022年旧文），识别其受时代限制的陈旧庸俗立论（如“母凭子贵依然是人生赢家”）；
  3. **第三步（结合当下升级）**：用最新进展（2026年儿子成年催母搞事业、《重生2》泥泞反杀）作为武器，完成对旧结论的降维打脸与立论升级。

### SOP-04 动笔前必过【待核清单（Uncertainty Review Sheet）】
- **痛点**：涉及公众人物争议、司法大案或未上映新片时，盲目脑补容易引发严重的事实硬伤或法律公关反噬。
- **强制规则**：
  1. 严格落实 2026-09-25 待核清单机制，动笔前必须提炼 3 条以内的口径表（U01-U03）；
  2. 包含拿不准点、我的保守建议、备选方案及影响正文哪一段；
  3. 待核项经 controller 确认或默认后方可落盘起草，违背待核决议的表述视为严重违规。

### SOP-05 “会话做确认，侧边做交付”的低噪长文交付闭环
- **痛点**：数千字的长文全量贴在会话框中，会严重污染对话上下文、快速耗尽后续多轮交互的 token 预算，且不便阅读排版。
- **强制规则**：
  1. 正文一律落盘至文件系统（如 `/home/allen/dsh/articles/*.md`）；
  2. 经由 `writing_audit` 与 `delivery_gate` 确定性门禁扫描；
  3. 会话内只输出：定版标题、字数统计、核心逻辑要点、绝对路径 Markdown 链接及自包含单页 HTML 阅读页链接，实现即点即看即复制。
