# 第一部：选题系统

## 一、核心原则（每天必背）

| 原则 | 说明 |
|------|------|
| **每天3篇** | 不是5篇，是3篇。37%零收益证实过量发文人效反而降低 |
| **每篇5部** | 每天15部片子，单部深扒可例外 |
| **3个维度不同** | 3篇文章方向必须错开，不能同质化 |
| **禁片≤2篇/天** | 禁片千次收益¥0.02-0.20，非禁片¥1.97-2.89，差10-50倍 |
| **至少1篇社会热点** | 洗标签+提CPM的核心 |
| **女性视角** | 读者63.8%是女性，每批至少1-2部从女性命运切入 |

### 选题筛选标准
- ✅ 有具体事件（不是观点、不是趋势）
- ✅ 有人的矛盾（言行打脸、立场反转、利害冲突）
- ✅ 有影视切口（电影、导演、演员、产业、政策）
- ✅ 有刀可下（能被毒舌拆解，不是纯歌颂）
- ❌ 事件超过1个月无新进展 → 不算热点

## 三、四大栏目体系

### 栏目A：🔪 银幕禁区档案（流量入口）
- 定位：禁片盘点类，高CTR流量入口
- 历史数据：CTR 12%，完读72%
- 格式：5部 × 一个国家/主题的禁片
- 例子："5部被封印的伊朗电影""全球5大顶级禁片"

### 栏目B：🎬 华语地下放映厅（双周1期）
- 定位：华语禁片专题，广东14.2%读者基本盘
- 例子：华语禁片导演的逃亡人生、禁片里的女演员

### 栏目C：🔥 银幕外的人间（每天第2篇·收入主力）
- 定位：社会热点影视交叉，洗标签+提CPM核心
- 历史数据：CTR 81%，RPM ¥2.89（非禁片是禁片10-50倍）
- 方向：人物命运通稿、产业黑幕、真实事件影视对比

### 栏目D：📽️ 电影史暗房（每天第3篇）
- 定位：冷门电影运动/导演/类型考古
- 方向：台湾新电影、香港新浪潮、日本V-Cinema、罗马尼亚新浪潮

## 四、每日排兵布阵

| 篇序 | 栏目 | RPM | 说明 |
|------|------|-----|------|
| 第1篇 | A或B | ⚠️低 | 流量入口 |
| 第2篇 | C | ✅高 | 当天收入主力 |
| 第3篇 | D | ⚠️低 | 维持调性 |

## 五、选题复用规则

| 层级 | 规则 | 说明 |
|------|------|------|
| 片子级 | 永不复用 | 同一片子在所有时间线上不复用 |
| 方向级 | 14天后可复用 | 必须换切入角度 |
| 方向+角度级 | 30天不复用 | 同角度30天不重复 |

## 六、收益驱动策略

致命数据：
- 禁片千次阅读收益 ¥0.02-0.20
- 社会热点影视交叉千次收益 ¥1.97-2.89（10-50倍差距）
- 37%（26/71篇）零收益 → 每发3篇有1篇白干

洗标签策略：
- 每周至少2篇社会热点影视交叉
- 每天禁片≤2篇
- 禁片之间穿插非禁片，让算法看到"这个号不止是禁片"

# 第二部：写作标准

## 一、标题锻造（核心中的核心）

### 标题公式（6种钩子）

| 钩子类型 | 公式 | 示例 |
|---------|------|------|
| **数字钩** | [数字]+[结果/对比] | 96岁/2077万/5部 |
| **认知钩** | "你以为X"→"其实Y" | "别急着感动"/"被封过" |
| **情绪钩** | [暴力动词]/"别再"/"求求了" | "撕碎"/"封过！" |
| **利益钩** | "怎么样才能"+[好处] | "先算明白" |
| **悬念钩** | "直到我发现"/"背后的真相" | "人性底色" |
| **身份钩** | [人群]+"[共性]" | 华语/国产片 |
| **极端反差钩** | [极端数字/身份]+[普通行为] | 96岁奶奶摆摊还债 |
| **名人钩** | [事件]+[名人A][名人B]难辞其咎 | 汪涵姚晨 |

### 标题规则
- **≤28字**，20字内最佳
- 数字前置 + 匕首式动词驱动
- 有结果感、冲突感、争议感
- 优先用词：争议巨大/长期冷藏/再未公映/鲜为人知/银幕禁区/原版更完整
- 禁用词：被禁/被封/禁播/封杀/删减XX分钟/尺度炸裂

### 标题锻造自检（每次写标题必过）
- [ ] 用了哪种钩子？（6种之一）
- [ ] 字数≤28字？
- [ ] 有数字或具体信息吗？
- [ ] 能让人产生好奇吗？（念给AI听，看"然后呢"）
- [ ] 情绪够不够狠？（"撕碎">"讲述"）

## 二、开篇规则

### 开篇三不要
- ❌ 不能从"今天给大家推荐几部电影"开始
- ❌ 不能温吞、不能端水
- ❌ 不能解释太多基础概念（读者不是小白）

### 开篇公式
**定义式开局：** 200字内进第一部
```
华语电影的世界里有一条看不见的线——
过了这条线，你的电影就不是电影，是证据。
```
**倒叙式开局：** 把最炸的结果甩第一句
```
一个96岁的老人，又一次冲上热搜。
```
**否定式开局：** 否定行业常识
```
片场里，导演已经说了不算了。
```

## 三、正文规则

### 每部电影拆解法
**剧情→争议→演员牺牲→社会隐喻**（揉进文章里，不能写成标签）

### 每部电影必须有
- 故事钩子（吸引继续读）
- 具体画面（视觉/听觉/气味/触觉至少一样）
- 争议点（为什么被禁/为什么争议）
- 人物命运（导演/演员后续怎样）
- 社会切口（能引发讨论的切入点）

### 段落规则
- 短句、狠句、带刺、有画面
- 每段不超过6行，最好2-4行
- 不要写成：`社会隐喻：xxx` `剧情：xxx`（不能有标签化冒号）

### 语言风格
- 推荐气质词：生锈的手术刀/隐秘的脓包/潮湿的地下室/蒙尘的录像带
- 禁用词：值得一提的是、值得注意的是、如此看来（AI腔）
- 语言要像冷刀子，不是喊口号

### 女性视角硬规则
- 写女性角色时不消费她的痛苦
- 不把侵犯、伤害、裸露当噱头
- 重点写：她为什么没有选择/为什么不能逃
- 她的身体不是卖点，她的命运才是刀口

## 四、金句模板库

### 五大金句公式

| 公式 | 示例 |
|------|------|
| **对比法** | "不是X，是Y。""X倒了，Y还在。" |
| **递进法** | "X。和Y。更Z。"（三短句递进） |
| **悖论法** | "最大的X，是Y。""这不是X。这是Y。" |
| **画面法** | 数字+场景切片+五个独立短句排比 |
| **身份���** | "X不是一个人，是Y。" |

### 金句植入规则
- 每部/每节结尾：至少1个金句
- 全文结尾：压轴金句，全文情感高潮
- 小标题：尽量本身就是半个金句
- 频率：每300字≥1个金句

## 五、结尾规则

### 结尾公式
- 必须升华，但不能鸡汤、不能硬拔高
- 变体句式（不要每篇机械重复）：
```
我们以为自己在看尺度。
其实是在看人性被撕开后的横截面。
```

### CTA结尾（四选一）

| 类型 | 示例 |
|------|------|
| **投票式** | "这5部华语争议电影，你看过几部？" |
| **挑战式** | "如果你还觉得国产片不敢拍，把这几部的名字念一遍。" |
| **追问式** | "你觉得一部电影最该被害怕的，是画面，还是它说出的真相？" |
| **总结式** | "真正狠的电影，从来不靠喊。" |

## 六、过审红线指南

### 敏感词替换表

| ❌ 不写 | ✅ 替换为 |
|---------|----------|
| 禁播/被封/封杀/被禁 | 争议巨大/长期冷藏/再未公映/鲜为人知 |
| 删减XX分钟 | 原版更完整 |
| 审查/审核 | 当时的标准/尺度考量 |
| 强奸/轮奸/性侵（画面） | 遭遇侵犯/梦魇般的经历 |
| 尺度炸裂/全网封禁 | 银幕禁区/争议之作 |

### 绝对死线（出现即换片/重写）
- 性器官、身体部位露骨描写
- 强奸、性侵直白画面描写
- 婴儿/幼儿/儿童的暴力/性内容
- 食人、排泄物等极端恶心画面
- 含具体领导人姓名的政治影射

### 过审原则
- 性场景不写画面，转写权力关系/心理变化
- 暴力必须挂钩社会解读（没社会解读的血腥只是低级刺激）
- 不主动撞红线，内容足够锐利但别找死

## 常用替换词表

| 想写 | 改用 |
|------|------|
| 被禁 | 争议巨大 |
| 被封 | 长期冷藏 |
| 尺度大 | 原版更完整 |
| 删减 | 有过更完整的版本 |
| 审查 | 特定年代的门槛 |

## 常见错误（避坑）

1. 写成"社会隐喻：xxx"格式 → 删除标签化冒号，揉进正文
2. 开头科普"什么是禁片" → 读者不是小白，删掉
3. 结尾突然端庄 → 保持毒舌风格，结尾也要带刺
4. 每篇机械重复"尺度是假真相是真" → 换变体句式
5. 过度使用感叹号 !!! → 用短句和问号代替
6. AI腔"值得一提的是" → 删掉，直接说事
