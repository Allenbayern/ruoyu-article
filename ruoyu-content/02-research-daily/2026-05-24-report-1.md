
### 📝 爆文B：96岁奶奶还清2077万

**基本信息：**
- 平台：今日头条
- 类型：热点解析/反常识打假

**结构拆解：**

```
标题：96岁奶奶还清2077万，真靠摆摊？别急着感动，先把账算明白
      ↑ 热点人物 + 反常识提问 + 命令式钩子("别急着X，先Y")

【开头钩子】
"一个八九十岁的老太太，靠街头摆摊，真能还清这么多钱？"
→ 直接挑战主流叙事的核心逻辑
→ 但立刻圆场"这个问题一点也不冒犯"

【叙事弧线】
1. 建立共识：陈金英的确还清了2077万，确实值得尊敬
2. 核心质疑："还清2077万" ≠ "靠摆摊还清2077万"
3. 拆解还债结构：
   - 大头 = 卖厂房/房产/设备/库存
   - 小头 = 摆摊收入
   - 可能因素 = 拆迁款（诚实标注"具体数额不统一"）
4. 核心论点：这不是励志，是不算账。如果没有几十年的资产积累，普通人摆摊还不了
5. 拔高：她真正牛的是"明明可以不还却选择了还"
6. 警示：不要从这篇推导出"所有创业失败的人都必须这样赎罪"

【核心金句】
- "把故事写浅了" → 对全网的概括性批判
- "不是励志，是不算账" → 最炸的一句话
- "她把'法律允许'当成'良心可以不管'的对立面" → 非常精准
```

**爆文基因分析：**

| 维度 | 评分 | 分析 |
|------|------|------|
| 反常识冲击 | ⭐⭐⭐⭐⭐ | 全网在煽情，它在算账 = 绝对差异化 |
| 信息密度 | ⭐⭐⭐⭐⭐ | 厂房、房产、库存、拆迁款，每项都有据 |
| 态度分寸 | ⭐⭐⭐⭐⭐ | 既"刺破"又不"踩"——肯定诚信，只是拆解叙事 |
| 分享动机 | ⭐⭐⭐⭐⭐ | 认同("终于有人说实话了") + 装逼("转发让别人也清醒一下") |
| 风险控制 | ⭐⭐⭐⭐⭐ | 结尾专门写明不是道德绑架 |
| 时效性 | ⭐⭐⭐⭐ | 热点已经发酵了一段时间，属于"深度跟进"而非"抢首发" |

**可复用的公式：**
> 「别急着感动，先X」→ 反套路标题公式，适用所有"全网一边倒"的热点
> 「不是A，是B」→ 核心论点公式
> 诚实标注信息不确定性 → 建立信任感（"拆迁款具体数额不统一"）
